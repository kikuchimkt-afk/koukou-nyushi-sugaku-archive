- 最終更新: 2026-09-10（JST）

- 現在の収録数: **136題・570ページ**（北海道8題・福岡県11題・長野県3題・群馬県20題・沖縄県27題・岩手県37題・徳島県12題・岐阜県14題・青森県4題）

数と式／方程式／方程式の利用／**規則性**／関数／図形／図形の証明／データの活用。

このファイルを、Mathmaticaの年度別進捗に関するリポジトリ内の正本とする。

## 共通ルール

- 小問集合は除外する。
- 対象は中1・中2の単元で構成される独立大問とする。
- 中1内容の混在は許容するが、**中3内容が混在する大問は除外する**。
  中3内容＝展開・因数分解、平方根、二次方程式、y=ax²、相似、円周角、三平方の定理、標本調査。
- **中3内容の判定は、設問だけでなく問題文の過程と解説の過程も対象とする。**
  解答者が中3の公式・定理を使う必要がなくても、問題文または解説の途中式に中3内容が現れる大問は除外する。
  採用の可否は、問題ページと解説ページの両方を画像で確認してから決める。
- **学校裁量問題は原則除外する。** 北海道の裁量問題は三平方の定理・相似・空間図形を含む構成が続いており、中1・中2の範囲に収まらない。
- 単元判定は解説冒頭の単元見出し（大問番号に続く丸括弧内の単元列）を第一の根拠とし、大問の全設問も確認する。
- 問題、解答用紙、正解、解説のページレイアウトと監査基準は、`koukou-nyushi-database` の
  `docs/高校入試_大問抜粋PDF作成・ページレイアウト手順.md` を正本とする。

## 判定の意味

- **選定済み**: 原本を画像で確認し、採用・除外を確定した。
- **実装済み**: `data/archive.generated.json` に収録され、PDFと画像プレビューが公開されている。
- 年度別表の `—` は「実装0題」を示す。監査済み0題を意味しない。

## 既存22題のPDF作成・実装監査（2026-09-08）

- 22題すべてを、問題 → 当該大問の解答欄 → 数学全問の正解 → 当該大問の解説、の順でA4 PDFにした。
- 問題・正解・解説は820dpi、解答欄は2000dpiで原本から生成し、A4配置後の実効解像度600dpi未満を生成時エラーとした。最終22冊の最小値は607dpi。

- 初回監査で見つかった境界不足を修正して再生成し、北海道3冊・福岡県9冊を独立再監査した。長野県3冊を含む最終22冊はすべてPASS。
- 固定した基底ビルダーで再生成した後も、200dpiの全102ページ画像は監査済み版とSHA-256が102/102一致した。
- `output/pdf/*_最終版` と `.release-assets` の22冊は、監査済みPDFとSHA-256が一致することを確認した。
