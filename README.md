# Mathmatica（マスマティカ）

公立高校入試の数学大問を、学年・領域・年度・都道府県・単元で探し、画像で素早く比較できる講師向けアーカイブです。

アプリ名は暫定です。

## 収録の方針

- 対象は中1・中2・中3の単元で構成される独立大問とする。
- **小問集合は収録しない。**
- 学年は、大問の設問・問題文の途中式・解説過程で必要となる最上位学年に分類する。複数学年の内容が混在する場合も、大問全体を1題として収録する。
- 単元判定は解説冒頭の単元見出しを第一の根拠とし、大問の全設問も確認する。学校裁量問題・追加問題は、本試験の共通問題と区別するため原則収録しない。

分類は、授業で単元を指定するときの言い方に合わせて、中学数学の大きめの単元8つとする。

| 単元 | 主な内容 |
|---|---|
| 数と式 | 正負の数、文字式、式の展開・因数分解、平方根 |
| 方程式 | 一次方程式、連立方程式、比例式、二次方程式 |
| 方程式の利用 | 文章題、速さ・割合、図形への方程式の応用 |
| 規則性 | 並び方の規則、文字式による説明、数の性質 |
| 関数 | 比例・反比例、一次関数、二乗に比例する関数、グラフの読み取り |
| 図形 | 作図、平面・空間図形、相似、円、三平方の定理 |
| 図形の証明 | 合同・相似の証明、平行線と角、円の性質 |
| データの活用 | 度数分布、代表値、箱ひげ図、確率、標本調査 |

最終版フォルダ名（`中2数学_規則性_最終版` など）を単元判定の第一の根拠とし、
フォルダ名で決まらない場合はファイル名の詳細単元から判定する。

## 講師向け選定機能

- 問題カード／単体プレビューから候補を「選定付箋」に保存
- 付箋は同じブラウザに保持され、再読込後も選定状態を復元
- 複数問題の問題・解答用紙・正解・解説を、問題単位で連続プレビュー
- 選定した高解像度PDFを付箋順に結合し、1つのPDFファイルとして取得

PDF結合はブラウザのメモリ負荷を抑えるため、10題かつ合計120MBまでです。PDFは同一ドメインのID照合済みAPIから3MB単位で取得し、全ページを付箋順に直接結合します。ZIPは作成しません。

## 公開構成

- Vercel: アプリ本体と軽量JPEGプレビュー
- GitHub Release: 印刷用の高解像度PDF（タグ `pdfs-v1`）
- `data/archive.generated.json`: 学年追加に対応する共通データ

PDFをVercelのビルドへ含めないため、今後、学年・県を追加してもデプロイ容量を抑えられます。

## 開発

```powershell
npm install
npm run dev
```

ローカルURL: `http://127.0.0.1:3180`

## PDFからプレビューを再生成

`SOURCE_ROOT` 直下の `中1数学_データの活用_最終版` など、`中[1-3]数学_*_最終版` に一致するフォルダを読み込みます。

```powershell
$env:SOURCE_ROOT = 'C:\path\to\output\pdf'
$env:PDFTOPPM = 'C:\path\to\pdftoppm.exe'
$env:RELEASE_TAG = 'pdfs-v1'
npm run build-content
npm run check-content
```

生成物:

- `public/previews/<問題ID>/page-*.jpg`
- `data/archive.generated.json`
- `.release-assets/*.pdf`（Git管理・Vercel送信の対象外）

再生成時は、現在の最終版PDFに対応しない古いプレビューとリリース用PDFを自動的に削除します。各PDFにはSHA-256由来の `contentVersion` を付与し、プレビュー・直接PDF・結合用APIのURLへ反映します。

ファイル名の規則:

```text
{実施年}年実施_{県名}_中{学年}数学_{詳細単元名（要素1・要素2・要素3）}.pdf
```
